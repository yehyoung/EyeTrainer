# EyeTrainer 👁️ 久坐族保健訓練網頁

專為久坐辦公族設計的訓練網頁：眼睛遠近變焦（睫狀肌）、眼球運動（外眼肌）、視覺放鬆、暗適應與明暗調節，
以及在家就能完成的等長運動、無跳躍高強度間歇、骨盆底肌訓練與自律神經調節。
純前端、零後端，可離線使用；規劃詳見 [PLAN.md](PLAN.md)。

**🌐 線上使用：https://yehyoung.github.io/EyeTrainer/**

## 功能

### ☸️ 動態藏輪圖（眼球運動）
- **五種圖形**：藏輪圖（魚骨輪臂）、雪花圖、星芒圖、花瓣圖、迷宮圖
- **四種模式**：描邊（亮點沿圖形輪廓等速行進）、旋轉、呼吸縮放、軌跡追蹤（8字／星形／波浪／螺旋）
- 960×640 大畫布，速度三段可調

### 🎯 遠近變焦訓練（睫狀肌）
- **對焦調節圖**：字母「大而清晰 ↔ 小而模糊」循環，模擬物體遠近，訓練對焦
- **手指凝視法**：提示音＋中文語音引導「看近（螢幕）／看遠（3 公尺外）」交替

### 🌀 3D 立體圖（Magic Eye）
- Canvas 即時生成隨機點立體圖（SIRDS，Thimbleby–Inglis–Witten 完整演算法，無鬼影）
- **基本／進階兩種難度共 12 種隱藏圖案**（進階含圓環、月牙、笑臉等鏤空圖形）
- 平行法／交叉法、對焦輔助點、答題驗證、答對後「保持融像 20 秒」倒數

### 🌙 暗適應與明暗調節
- **暗適應階梯**：20 分鐘暗適應引導，12 階灰度每 2 分鐘記錄一次閾值，自動繪出暗適應曲線（含 rod–cone break 標示）
- **明暗交替適應**：亮暗相緩慢交替，暗相中搜尋低對比數字並即時揭曉答案，訓練明暗切換的反應
- **餘光偵測（averted vision）**：固定注視深紅十字，用餘光判斷微弱亮點方向；自適應階梯找出個人偵測極限
- **眩光恢復計時（photostress recovery）**：強光後計時到看清低對比數字，留下可追蹤的基準線
- 附飲食（維生素 A／葉黃素／鋅）、夜間用眼習慣與「該就醫的警訊」三張對照卡

### 😌 放鬆休息
- 20-20-20 護眼提醒（循環計時＋語音）、節拍眨眼、掌心熱敷（palming）引導

### 💪 等長運動（Isometric）
- **六個項目**：靠牆深蹲、棒式、掌心互推、頸部等長、臀部收縮、握力維持
- 圓環進度計時，自動循環「用力維持 → 休息 → 下一組」，含語音與提示音
- 維持秒數／組數／休息時間皆可調；預設帶入降血壓研究方案（2 分鐘 × 4 組）
- 訓練中持續顯示「不要憋氣」提醒（憋氣會使血壓瞬間飆升）

### 🔥 安靜燃脂（無跳躍高強度間歇）
- **四種課表**：四分鐘 Tabata、七分鐘全身、十二分鐘燃脂、深夜零落地
- 19 個動作全部<strong>不跳躍、不跺地</strong>（波比改踏步、滑冰者改跨步、高抬腿改輕放踏步），樓下聽不到衝擊音
- 每個動作都有 AI 生成的<strong>動作示意圖</strong>，訓練中顯示在側欄，另有可先瀏覽一遍的「動作圖鑑」
- 圓環倒數＋語音換動作，休息時先報出下一個動作；每個動作附步驟與「靜音要點」
- 動作時間／休息／輪數可調，暖身與緩和可開關
- **一分鐘心率恢復（HRR₁）**測量工具：15 秒脈搏 ×4 → 休息 1 分鐘 → 再測，自動換算下降幅度並留下紀錄

### 🩸 腿部靜脈回流（小腿肌肉泵）
- **五種練習**：踝泵運動、坐姿腳跟腳尖交替、小腿提踵、小腿與膝窩伸展、抬腿休息
- 腳踝動畫＋圓環倒數引導節奏（背屈／蹠屈角度由訓練狀態即時推算），次數與組數可調
- 靜脈瓣與肌肉泵解剖圖、每個動作的示意圖與步驟
- 久坐族日常對策（不讓椅緣壓住膝窩、彈性襪、抬腿、久站對策）與 5 項就醫警訊
- 誠實定位：運動無法讓曲張的血管消失，只能改善症狀與延緩惡化

### 🌸 骨盆底肌訓練（凱格爾）
- **三種課程**：慢縮（耐力）、快縮（反應）、完整課程（符合臨床建議處方）
- 圓球上提／下降動畫引導收縮與放鬆節奏，搭配語音與提示音
- 慢縮維持秒數（3/5/8/10 秒）與次數可調

### 🫁 自律神經調節
- **六種技巧**：共振呼吸（6 次/分）、4-7-8 呼吸、生理性嘆息、箱式呼吸、哼鳴呼吸、漸進式肌肉放鬆
- 呼吸圓球隨吸氣脹大、吐氣縮小，逐幀引導節奏，搭配語音與提示音
- 共振呼吸提供三段節奏（入門 7 次/分、標準 6 次/分、深度 5 次/分），時長 2–10 分鐘可調

### 其他
- 每個練習附「🎯 目的・🔬 原理・📋 方法」說明卡
- 📈 訓練進度：連續天數、累計時間、立體圖答對率（localStorage）
- ⚠️ 安全機制：首次使用安全問卷，高度近視者鎖定慢速模式；全站免責聲明
- 深色琥珀低藍光主題

## 本機開發

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 輸出 dist/（純靜態）
```

## 部署到 GitHub Pages

本倉庫已內建自動部署（[.github/workflows/deploy.yml](.github/workflows/deploy.yml)）：

1. push 到 `main` 分支即自動觸發：安裝依賴 → `vite build` → 部署 `dist/` 到 GitHub Pages
2. 首次部署會自動啟用 Pages（Source: GitHub Actions）
3. 網址格式：`https://<帳號>.github.io/<倉庫名>/`

`vite.config.js` 已設定 `base: './'`（相對路徑）＋ hash 路由，因此也可直接部署到 Cloudflare Pages、Netlify 或任何靜態主機，無需額外設定。

## 技術

Vue 3 + Vite + vue-router（hash 模式）、Canvas 2D、Web Audio、SpeechSynthesis、localStorage。

## 免責聲明

本工具僅供保健參考，無法治療任何疾病，不能取代專業醫療診斷與治療。

- **暗適應訓練**：暗適應的速度由視紫質再生的化學反應決定（約 20–30 分鐘），無法靠練習加快；
  本模組的價值在於用對餘光、避免自己破壞暗適應、以及留下可追蹤的基準線。
  「眩光恢復計時」不是臨床檢查，只能與自己在相同螢幕、相同房間亮度下的紀錄比較，不可用於自我診斷。
  眩光測試會出現短暫強光，有視網膜病變、偏頭痛畏光、近期眼部手術或服用光敏感藥物者請略過；
  有光敏性癲癇病史者請避免明暗交替練習。若夜間視力是近期才明顯變差，請先看眼科。
- **眼睛訓練**：無法治療近視或老花。高度近視（600 度以上）或視網膜病變者請避免快速眼球運動，
  並先諮詢眼科醫師；若出現閃光感、飛蚊突增、視野缺損請立即停止並就醫。
- **靜脈回流訓練**：運動<strong>無法讓已經曲張的血管消失</strong>——瓣膜受損是結構性損傷，不會因訓練復原。
  Padberg et al. (2004) 的隨機對照試驗顯示 6 個月訓練能改善小腿泵射出分率與肌力，但靜脈逆流、
  生活品質與疾病嚴重度評分並未改變；2023 年 Cochrane 回顧（5 篇試驗、146 人）認為證據仍不足。
  若單側小腿突然腫脹、發熱、壓痛（可能是深層靜脈栓塞），請立即就醫，不要按摩也不要先運動；
  膝窩腫塊需超音波鑑別（貝克氏囊腫、小隱靜脈瘤、膕動脈瘤都長在同一位置）。
- **安靜燃脂（高強度間歇）**：這是本站唯一的高強度項目。有未控制的高血壓、心血管疾病、近期手術、
  懷孕或膝踝下背舊傷者，請先諮詢醫師；出現胸痛、胸悶、心悸、頭暈、冒冷汗請立即停止並就醫。
  「一分鐘心率恢復下降 12 下」的門檻來自標準跑步機運動測試（Cole et al., NEJM 1999），
  與在家徒手運動的情境不同，只能當作跟自己比較的趨勢指標，不可用於自我診斷。
- **等長運動**：維持出力期間血壓會短暫升高，務必全程正常呼吸、切勿憋氣。
  有高血壓、心血管疾病、青光眼或視網膜病變者請先諮詢醫師。
- **骨盆底肌訓練**：請勿反覆以「中斷尿流」作為練習方式。放鬆與收縮同樣重要，
  過度訓練可能造成骨盆底肌過度緊繃；有骨盆疼痛或復健需求請諮詢醫師或骨盆底物理治療師。
- **呼吸練習**：出現頭暈、手腳發麻或刺痛代表換氣過度，請立即停止並回到自然呼吸。
  含屏息的技巧若您懷孕、有心血管疾病、癲癇病史或正在恐慌發作，請縮短或略過屏息段落。
  自律神經失調症狀與心臟、甲狀腺等疾病高度重疊，若有持續心悸、胸痛、暈厥請務必就醫。
